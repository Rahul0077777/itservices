# NexaTech IT Solutions — Frontend

Modern, high-performance IT solutions agency client application built with **React + Vite + TypeScript + Tailwind CSS**.

## Features
- **Responsive Navigation**: Brand navbar with smooth scrolling and mobile drawer.
- **Hero Section**: Exact visual layout with dashboard laptop & mobile device mockups, trust badges, and quick CTAs.
- **Services (7 cards)**: Web Development, MERN Stack, AI Automation, Mobile App Development, SaaS / CRM, UI/UX, and API Integration.
- **Featured Projects**: Portfolio showcase (Zaya Travels, CRM Platform, GoyaFly, TaskFlow) with architecture modal and repository links.
- **Work Process**: 4-stage methodology (Discover, Plan, Build, Launch).
- **Why Choose Us & Tech Stack**: Transparent value proposition, modern stack badges, and interactive CTA card.
- **Testimonials**: Clean evaluation feedback component.
- **FAQ**: Fully accessible accordion with keyboard navigation.
- **Contact & Inquiry Form**: Form validation with React Hook Form + Zod, loading/success/error states, and real backend submission.

## Setup & Running

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run production build
npm run build

# Preview build
npm run preview
```

## Environment Variables
Create a `.env` file in `nexatech/frontend`:
```env
VITE_API_BASE_URL=http://localhost:5000/api
```
