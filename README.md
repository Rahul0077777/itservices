# itservices — NexaTech IT Solutions

A full-stack IT services and agency platform featuring modern web development, mobile solutions, cloud infrastructure, and AI automation.

## Project Structure

- **`nexatech/`**
  - **`frontend/`**: Modern React + TypeScript + Tailwind CSS application showcasing agency services, portfolio projects, client testimonials, and interactive contact forms.
  - **`backend/`**: Node.js + Express + TypeScript API handling inquiries, validation, automated email notifications, and service endpoints.

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Running Frontend
```bash
cd nexatech/frontend
npm install
npm run dev
```

### Running Backend
```bash
cd nexatech/backend
npm install
npm run dev
```
